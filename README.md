Система за управление на библиотека
Описание

„Система за управление на библиотека“ е конзолно приложение, разработено на C# и .NET. Проектът позволява управление на книги, автори и категории чрез лесен за използване интерфейс.

Данните се съхраняват в MySQL база данни, а достъпът до тях се осъществява чрез Entity Framework Core с подход Code First.
